# Agent Registry

Roster of coding agents that have worked in this repository. Registration is
**one-time**: add a section the first time a session works here — nothing
else is expected afterwards. The registry is a record, not a control surface:
when a session ends, its state is compacted into the active plan (the Next
action and round entries), and a fresh session rebuilds from those artifacts.

## How to join

Append one section at the end of this file; the heading is your stable agent
id.

```markdown
## <agent-id>

- Model: tool name and model version
- Joined: YYYY-MM-DD
- Focus: usual areas of responsibility (optional)
- Notes: anything the next session should know (optional)
```
